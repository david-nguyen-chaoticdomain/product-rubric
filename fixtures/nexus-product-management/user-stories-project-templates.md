# User Stories: Project Templates | Prepared by Marcus Webb

Stories for the first version of Project Templates. The requirements document is PRD: Project Templates. Each story carries its acceptance test in one line.

1. As a workspace admin starting a new project, I want to create it from a template our team has used before, so that the project opens with our usual tasks and docs already in place.
   Acceptance: the new project contains the template's tasks and docs, with due dates shifted to the creation date.

2. As a project lead who has just finished a well-run launch, I want to save that project as a template, so that the next launch starts from what worked.
   Acceptance: saving offers tasks, docs, and roles as separate choices, and the original project is unchanged.

3. As a template owner, I want to edit my template after projects have been made from it, so that improving the template never disturbs work already under way.
   Acceptance: editing a template changes no existing project.

4. As an admin setting up a project for a client, I want templates to handle my whole onboarding, so that setup is effortless.
   Acceptance: the admin finishes setup without help.

5. As Nexus, I want to suggest templates to new admins, so that engagement with the feature rises.
   Acceptance: suggestions appear in the new-project flow.

6. As a workspace admin, I want to share my best template to the community gallery, so that other teams can start from it.
   Acceptance: a submitted template appears in the gallery after moderation.

7. As a new admin who has never used Nexus, I want to preview a template's tasks and docs before I commit to it via a carousel of cards, so that I can choose with confidence.
   Acceptance: the preview shows every task title and doc title in the template without creating a project.

8. As a team member invited to a project, I want the project's tasks to show which ones came from the template, so that I know which tasks I can rename or delete freely.
   Acceptance: template-born tasks carry a visible marker until first edited.
